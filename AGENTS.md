# Reglas del proyecto

- Aplicación local de demostración con datos sintéticos. Nunca cargar datos reales de salud.
- React + TypeScript + Vite + React Router, CSS propio; Express + TypeScript, Prisma + SQLite.
- Controlar rol y propiedad de cada cliente en el servidor. Validar toda entrada; errores uniformes.
- No exponer secretos de servidor en frontend, Git, registros ni mensajes de error.
- IA vía backend y n8n, consentimiento explícito para cada envío externo. Propuestas requieren aprobación del entrenador.
- No reproducir cuestionarios o escalas protegidas. No diagnosticar, prometer prevenir lesiones ni inventar medidas ausentes.
- Conservar etiquetas ambiguas y documentar su significado; kg y cm canónicos, libras con factor 0.45359237.
- Mantener PROGRESS.md por hito; máximo 3 rondas de auditoría con evidencia ejecutable.
- Compilar y ejecutar pruebas significativas en cada hito. Documentar límites de verificación.
- UI en español, controles con etiquetas, foco visible, teclado y movimiento reducido.
- No realizar ramas, commits, PR, publicaciones ni cambios remotos de GitHub.
